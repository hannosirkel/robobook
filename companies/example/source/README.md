# Example Source Pack

This directory contains a small synthetic source pack for the publishable
`companies/example` workspace.

It is not real company data and it is not intended to mirror any live
Simplbooks company exactly. Its purpose is to demonstrate the public workflow:

- WooCommerce sales as the recurring invoice basis
- Stripe and PayPal as payment-processor settlement evidence
- Printful as a fulfillment-cost source
- bank transactions as pre-imported cash evidence

The matching worked artifacts live under `companies/example/artifacts/`.
